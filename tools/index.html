Tools ​

Small web tools made while building Openpod. They all run in the browser, with nothing to install.

OpenPod SyncFill the SD card from your music folders, right in the browser: see what's new, convert what the player can't play, remove albums.Click wheel designerGenerate a capacitive click wheel footprint (pads and edge cuts) as PNG for KiCad, and simulate how the finger position is interpolated.PinoutSee which STM32F446 pin drives what on the final board (LQFP100) and on the Nucleo prototype (LQFP64).UI builderPreview every firmware screen, tweak the colour palette and export the sprites and theme headers.Radio France podcast downloaderA Tampermonkey userscript: on any Radio France podcast page, tick the episodes and download them into ~/Podcasts, ready to sync.

The Radio France downloader is a userscript: install Tampermonkey, open the link and confirm. It needs Chrome or Edge (the File System Access API); Firefox/Safari fall back to a normal download. Once the episodes are in ~/Podcasts, add that folder as a library in OpenPod Sync and it syncs to the card.

Full pin tables: LQFP100 (final board) · LQFP64 (Nucleo-F446RE).
