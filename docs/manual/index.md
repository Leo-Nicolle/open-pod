## Getting started
Charging, turning on and off, the hold switch, first boot.

## Controls
The click wheel: scrolling, the centre button and the four buttons (menu, play/pause, previous, next). Fast scroll in long lists: turn faster and each click jumps to the next three-letter, two-letter, then first-letter prefix, shown in the middle of the screen. Haptic feedback.

## Loading music
Preparing an SD card with the sync tool: supported formats (MP3, FLAC up to 48 kHz / 24-bit), cover art, how the library index and search are built. The index is one file, `openpod/index.pack`, read from the card as needed, so the library can be as big as the card. A card indexed by an older sync tool shows "Library needs a re-sync".

## Browsing and search
Genres, artists, albums, tracks. Searching the library.

## Bluetooth
Pairing headphones, reconnecting, forgetting and renaming devices.

## Battery and charging
Battery life, charging over USB-C, the battery indicator.
