## How to communicate with the screen ?

So, as I am using a [STM32F4](https://www.st.com/resource/en/datasheet/dm00037051.pdf), apparently I could use either DMA (Direct Memory Access) or  FSMC(). Claude says FSMC is faster, but he also said I could not use it with my chip (wrong), so I went for DMA, and we'll see annother day if FSMC is faster or not. 

The idea is: 
 - we send the 2 bytes of data for une pixel via D0-D15
 - we pulse the WRX pin simultaneously
 - we set the DCX pin to 0 for command, 1 for data
 - Usually there would be some bit manipulation to get the right bit on the right pins, but since my mapping is direct PC0 to PC15, I can just write the data directly to the GPIO port.

 ```cpp
 void setupPins() {
    // Control pins
    pinMode(TFT_DC, OUTPUT);
    pinMode(TFT_WR, OUTPUT);
    pinMode(TFT_RST, OUTPUT);
    pinMode(TFT_RD, OUTPUT);

    digitalWrite(TFT_WR, HIGH);
    digitalWrite(TFT_RST, HIGH);
    digitalWrite(TFT_RD, HIGH); 

    // Enable GPIO clocks
    RCC->AHB1ENR |= RCC_AHB1ENR_GPIOBEN | RCC_AHB1ENR_GPIOCEN;

    // Set all PC0-PC15 pins to output mode (data bus)
    GPIOC->MODER = 0x55555555;
    // Set all data pins to push-pull, high speed
    GPIOC->OTYPER = 0x0000;     // All push-pull
    GPIOC->OSPEEDR = 0xFFFFFFFF; // All high speed
  }

  inline void pulseWR() {
    GPIOB->BSRR = (1 << (9 + 16));  // WR low (PB9)
    __NOP(); // Small delay
    GPIOB->BSRR = (1 << 9);         // WR high (PB9)
  }

  inline void write16(uint16_t data) {
    // Here there should be some bits manipulation, 
    // but my pinout makes it EASY
    GPIOC->ODR = data;
    pulseWR();
  }

  void setBusToInput() {
    GPIOC->MODER = 0x00000000;
  }

  void setBusToOutput() {
    GPIOC->MODER = 0x55555555;
  }

  void writeCommand(uint8_t cmd) {
    digitalWrite(TFT_DC, LOW);
    write16(cmd);
  }

  void writeData(uint8_t data) {
    digitalWrite(TFT_DC, HIGH);
    write16(data);
  }

  void writeData16(uint16_t data) {
    digitalWrite(TFT_DC, HIGH);
    write16(data);
  }
```
