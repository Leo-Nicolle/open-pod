# Vibecoding the UI! 

Now that I have my screen connected with 8080 16bits parallel interface, I can start coding the UI.
I started with Adafruit GFX library, since I thought it would be simple and fast, turns out it was not fast enough. So I subscribed to claude, and my god he was good at it.

My god it is ugly! But it is FAST!  There is still some flickering when scrolling up, we'll see about that later.

Next I will get him to fix the alignments, make me some transitions between the screens, and add some animations. I did not beleive it, but he even made me a script to convert fonts into header files for fast rendering.

- Use my external PSRAM to store the screen buffer, but it was too slow ( I don't have Quad SPI on my IC)
- Use the Adafruit GFX library, maybe there are more clever ways to use it, maybe I should write more functions, but Claude was so excited about writing the UI that I let him do it his way.
