# Live bench

Watch the bench firmware live, drive the pod from here, and run the [benchmark](./bench) scenarios from the browser. The page talks to the Nucleo straight over USB with Web Serial (Chrome or Edge on desktop), so nothing needs installing. Without a board, <a href="?demo">try the demo</a>, which simulates one.
